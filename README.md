## ⚡ Live Web Demo
Deploy this repository to **GitHub Pages** to test the simulator live on any device.

### How to Enable GitHub Pages (1-Click):
1. Create a new repository on GitHub named `deadair-demo` under your GitHub account (`raybornlabs`).
2. Push the files in this folder to the `main` branch.
3. In your GitHub repository, go to **Settings > Pages**.
4. Under **Build and deployment > Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your interactive simulator is live at: `https://raybornlabs.github.io/deadair-demo/`!

## ✂️ What You Can Test in the Simulator:
- **Silence Threshold Dial (-30 dB):** Drag to see how DeadAir isolates softer speech vs pure silence.
- **Min Silence Duration (0.50 s):** Filter out quick micro-pauses and only target long pauses.
- **Padding Buffer (0.15 s):** Protect the start and end of every word so cuts always sound natural.
- **Review Mode:** Preview and inspect yellow markers on your timeline before committing.
- **1-Click Ripple Delete:** Watch silent gaps collapse with magnetic snapping and instant timecode savings.
- **Non-Destructive Auto-Backup:** Demonstrates automated sequence duplicating before any cuts are applied.
- **Audio Synthesizer & VU Meters:** Hear realistic speech pacing before vs after cuts.
